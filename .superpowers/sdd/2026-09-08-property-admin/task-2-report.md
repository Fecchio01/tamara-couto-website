## Implemented boundary

- `public.properties` with UUID identity, optional legacy ID, property fields, centavo pricing, JSON features, status constraint, timestamps, and indexes.
- `public.property_images` with a cascading foreign key to `public.properties`, ordered images, alt text, and indexes.
- `public.admin_users` keyed by `auth.users.id`, constrained to the `admin` role.
- RLS enabled on all three public tables.
- Anonymous reads limited to published properties and published property images.
- Authenticated mutations limited to users present in `admin_users` with `role = 'admin'`.
- Update policies include both `USING` and `WITH CHECK`.
- Admin membership has read-only RLS access; attempts to update the authorization identity are rejected.
- Private `property-images` bucket with storage object read access for published image metadata and admin-only insert/update/delete under `properties/` paths.
- No service-role key, user secret, or runtime credential was added.

- Restricted the public storage SELECT policy to `object.get_public`, `object.get_authenticated_info`, and `object.get_authenticated` through `storage.allow_any_operation`; storage listing is no longer included.
- Expanded pgTAP from 15 to 24 assertions: private bucket state, anonymous published-image read, anonymous draft-image rejection, anonymous listing rejection, anonymous upload rejection, non-admin property and storage update/delete rejection, and operation-scoped storage behavior.
- Added a `public.properties.updated_at` trigger that refreshes timestamps on edits.
- Added a `properties/%` check constraint to `property_images.storage_path`.
